# Neural Network from Scratch (NumPy)

A 3‑layer neural network built from scratch using only NumPy.

## Architecture
- Input: 4 features
- Hidden layer 1: 2 neurons (ReLU)
- Hidden layer 2: 2 neurons (ReLU)
- Output: 1 neuron (Linear)
- Loss: MSE

## What It Does
- Forward pass
- Backpropagation (manual gradients)
- Gradient descent
